# G9 MENTOR desktop — the 16 screens

Source of truth for routes and titles: `apps/desktop/src/app/router.tsx` (`SCREENS`). Every screen renders without Tauri and without a model (R-002, A09) against the deterministic mock transport (`apps/desktop/src/ipc/transports/mock.ts`), and every screen is exercised by `apps/desktop/src/app/screens/screens.test.tsx` in two conditions: fixture data, and a backend that answers `RESOURCE_UNAVAILABLE` for everything.

## Conventions shared by all screens

| Concern | Rule | Where |
|---|---|---|
| Provenance labels | Every displayed text carries `VERIFIED` (operator / system-deterministic record), `RECOMMENDATION` (model or skill output; advisory only) or `PROPOSED` (hypothesis awaiting an operator decision). | `src/app/components/Badge.tsx` |
| Model down | Any panel that would show AI output renders `Recommendation (model unavailable)` with the backend reason (`SystemStatus.model.reason`). Core planning, notes, timers, reviews keep working. | `src/app/components/Panel.tsx` (`ModelUnavailable`) |
| Missing data | `NO DATA — <reason>` (`role=status`). No placeholder numbers, no estimates. | `Panel.tsx` (`NoData`) |
| Errors | `ErrorDisplay` maps all 13 `ErrorCategory` values to a title, guidance, severity and a retry affordance for retryable categories; shows `approval_id` and the bound hash for `APPROVAL_REQUIRED`. Never shows internals. | `src/app/components/ErrorDisplay.tsx`, `src/lib/error-text.ts` |
| Identity | The UI never sets an actor. `ClientCommandMeta` has no `actor`; the mock refuses meta that carries one (`meta.actor_not_accepted`). | `src/ipc/client.ts`, `schemas/ipc/command-meta.schema.json` |
| Clock | "Today" is `system.status.clock` (backend clock + IANA zone), never `Date.now()` in the UI. Durations are backend `credited_ms` / `uncertain_ms`; the UI never derives elapsed time from wall-clock subtraction. | `src/app/hooks/useToday.ts` |
| Approvals | Protected operations answer `APPROVAL_REQUIRED(approval_id)`; the UI shows the `ApprovalCard` (action, resource, scope, parameters SHA-256, expected revision, expiry) and re-issues the same operation with `approval_id`. The webview requests; the trusted surface grants (Addendum A.7). | `src/app/hooks/useApprovalFlow.ts`, `src/app/components/ApprovalCard.tsx` |
| Offline | `system.status.network.egress_allowed === false` renders `OFF` / `OFFLINE` in the shell header, Mission Control and Research Center. | `src/app/layout/Shell.tsx` |
| Theme | Dark cinematic, restrained gold/cyan/green CSS variables; `High contrast` toggle persisted in `localStorage` (`g9.contrast`) and applied as `data-contrast` on `<html>`. Plain CSS. | `src/app/theme/theme.css`, `src/app/theme/useContrast.ts` |
| Markdown | Rendered only through `renderMarkdown` (marked → DOMPurify allow-list). No script/style/iframe/object/svg/img/form, no `on*`, `style`, `class`, `id`, data-*/aria-* attributes; URLs limited to http(s)/mailto/anchors; `target` removed, `rel="noopener noreferrer nofollow"` forced; link clicks are intercepted (no shell capability). | `src/lib/markdown.ts`, `src/app/components/MarkdownPreview.tsx` |

Global keyboard map: `Tab` through the skip link ("Skip to main content"), header controls, the 16-link navigation (`nav[aria-label=Screens]`, `aria-current=page` on the active link) and `main`. All actions are native `<button>`/`<a>`/form controls; no pointer-only interaction exists.

## Authority boundaries visible in the UI

- State-machine tables in `src/lib/state-machines.ts` mirror `crates/g9-domain/src/state.rs` (edge counts asserted in tests). They only enable/disable controls. The backend (or the mock, standing in for it) refuses illegal edges with `PRECONDITION_FAILED <machine>.illegal_transition`; the UI shows that error rather than pretending the transition happened.
- `useApprovalFlow` never fabricates approvals: it lists them from the backend and re-issues the original command with `approval_id`. The mock enforces hash binding, single use and 15-minute expiry exactly as `g9-policy` will.
- The mock transport is a labelled test double (`SystemStatus.transport === 'mock'`, badge `MOCK` in the header). Its fixture is `apps/desktop/src/fixtures/curriculum-week3.json` (week 3 of `data/curriculum/g9-ct9-480.seed.v0.json`, provenance `PROPOSED_SEED`).
