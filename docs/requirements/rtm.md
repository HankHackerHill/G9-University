# Requirements traceability matrix (RTM)

Source: handoff v6.0 §4 (R-001–R-018) and §18 (A01–A12, B01–B06). Status values: IMPLEMENTED (code + tests exist in this repository), PARTIAL (contract and tests for part of the requirement), PROPOSED (contract/schema only), BLOCKED (needs an operator gate). Test ids are greppable test function names. Executed-test evidence: `docs/evaluations/gate-evidence.md` (generated by the test `gate_evidence_document` in `crates/g9-evaluation/src/lib.rs`; scenario-level, A02 and A12 NOT RUN there) and `docs/release/wave2-integration-report.md` (workspace test counts, 2026-11-06). No Stage PASS report (`GOVERNANCE.md`) has been issued yet, so the gate map Status column below gives the harness result, not a stage sign-off.
