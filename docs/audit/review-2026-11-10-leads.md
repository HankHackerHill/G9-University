# Review of 2026-11-10: status of its 50 leads

On 2026-11-10 an internal code review of the whole repository recorded 50 leads (13 `app`, 13 `core`, 12 `storage-core`, 12 `storage-repos`): title, file, evidence, failure scenario, proposed fix and proof test each. Six were fixed explicitly the same week (CHANGELOG, "Fixed (2026-11-10 review leads)"); the list itself was never committed. Plan step PROC-7 (`docs/release/path-to-10.md`) recovered it and re-assessed every lead against the code of 2026-11-16 (commit `60850be`): one agent per batch decided FIXED, OPEN, PARTIAL, LATENT or NOT A DEFECT with file and line evidence, and a second agent tried to refute each verdict. They agreed on all 50.

| Status | Meaning |
|---|---|
| FIXED | the failure scenario cannot happen any more, and a named test would fail if it came back |
| OPEN | the failure scenario still happens through a production path (an operation, the CLI, recovery, backup or restore) |
| PARTIAL | part fixed, part still possible |
| LATENT | the weakness is in the code, but no production path reaches it today; it must be closed before a path is added |
| NOT A DEFECT | the lead was wrong, or the behaviour is intended and documented |
| OWNER | the fix needs a decision of the owner, stated in the row |

"Assessed" is the status found at `60850be`; "Now" is the status after the fix round of 2026-11-17 (fail-first tests, each group reviewed by an independent agent). Counts now: FIXED 10, LATENT 17, NOT_A_DEFECT 1, OPEN 18, PARTIAL 4.
