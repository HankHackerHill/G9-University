# G9 MENTOR security audit (2026-11-18), with web research up to 2026-11-16

Labels: VERIFIED (exact code read or exact page or search result seen), TESTED (a test in the repository proves it), INFERRED, ASSUMED, PROPOSED, NOT RUN.

Owner request: a further triple security audit that catches anything that could be bad and searches for everything known to 2026-11-16 (the research cut-off; the tool runs were made on 2026-11-18, and items dated after the cut-off are marked).

## Method

Five read-only reviewers, one per lens, each with web search: (1) dependency, platform and supply-chain advisories; (2) the Tauri shell, the IPC boundary and the React frontend; (3) storage, cryptography, authorization and integrity; (4) the AI adapter, skills and the mentor runtime (OWASP LLM and agentic lists, MCP and agent research); (5) the code and courseware added on 2026-11-18 (ADR-0023). Each reviewer had to give a source-to-sink path, the attacker's capability and a scenario, and could not edit files, run git or build. Every finding of severity LOW or above was then given to independent skeptics told to refute it (one for LOW, two for MEDIUM and above). Findings already recorded in `docs/audit/security-audit-2026-11-12.md`, `docs/audit/security-audit-2026-11-13.md` and `docs/audit/security-audit-2026-11-17.md` were not re-reported.

Result: no CRITICAL and no HIGH finding survived verification. One finding was reported MEDIUM and rated LOW by both skeptics. The reviewers' raw output was held in the session's scratch directory and is not committed (it quotes search results and pages that are untrusted external content); this report is the curated record.
