# g9-skill-engineer — methodology

Checklist: name == directory, description states use and not-use, negative triggers name concrete situations, procedure steps cite evidence, scopes table uses Read/Propose, output contract lists every result field, adversarial evals carry the three tags.

## Decision rules

- Every claim cites evidence refs; inferences carry confidence limits.
- The skill proposes; `g9-policy` decides; the operator approves.
- Abstain rather than guess when inputs are missing or untrusted.
