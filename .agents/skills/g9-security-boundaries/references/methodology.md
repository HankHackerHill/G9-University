# g9-security-boundaries — methodology

Boundaries B1–B8 (IPC, pipeline, storage, model, skills, imports, research, host). Each change: which boundary, which rule id, which test, which ST scenario. Metadata never grants; policy decides at action time.

## Decision rules

- Every claim cites evidence refs; inferences carry confidence limits.
- The skill proposes; `g9-policy` decides; the operator approves.
- Abstain rather than guess when inputs are missing or untrusted.
