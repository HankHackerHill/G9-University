# g9-release-recovery — methodology

Stage report sections: scope, approved actions, files, versions, executed test ids and results, performance, defects by severity, security impact, recovery status, change vs baseline, remaining risks, next exact operation.

## Decision rules

- Every claim cites evidence refs; inferences carry confidence limits.
- The skill proposes; `g9-policy` decides; the operator approves.
- Abstain rather than guess when inputs are missing or untrusted.
