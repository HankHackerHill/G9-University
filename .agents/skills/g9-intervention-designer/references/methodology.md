# g9-intervention-designer — methodology

Intervention = hypothesis + steps + budget + unseen retest + acceptance + delayed transfer probe. Lifecycle HYPOTHESIS → PROPOSED → REVIEWED → APPROVED → SCHEDULED → APPLIED → RETESTED → EVALUATED.

## Decision rules

- Every claim cites evidence refs; inferences carry confidence limits.
- The skill proposes; `g9-policy` decides; the operator approves.
- Abstain rather than guess when inputs are missing or untrusted.
